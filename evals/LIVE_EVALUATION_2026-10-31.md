## 这次完成的改动

- 任务 API 加入幂等键与取消接口；PostgreSQL 任务表、事务 Outbox、worker 租约、过期任务恢复和事件流配套更新。取消为协作式；租约可保护任务状态、事件和指标写入。
- 前端在 SSE 正常连接时停止额外轮询，断线时改用 5 秒轮询；评测客户端改用 3 秒轮询并遵守 `Retry-After`。
- 报告必须在摘要和实质性正文中直接引用已收集的证据 ID。引用清单只在正文 ID 全部属于已见证据时由程序整理；未知 ID、缺少正文引用等仍进入修复或失败路径。

## 生产容器链路

Docker 镜像重新构建，API、PostgreSQL 和 Redis 健康检查通过，worker、outbox、Prometheus 正在运行。`GET /ready` 返回 200。

- 一次网页研究任务：`POST /research` 返回 202；同一幂等键重复提交得到同一任务 ID；Celery worker 最终完成；约 42.17 秒、4 次模型调用。报告摘要和正文都有引用，8 个清单 ID 与正文 ID 一致。SSE 事件接口返回 200，包含完成事件。
- 一次生产文档检索：标明“合成测试”的 Markdown 上传返回 201；`/knowledge/search` 返回 1 条证据且包含预期数值；测试文档随后删除，返回 200。这覆盖了生产配置的 PostgreSQL/pgvector、混合检索和重排调用路径，但没有单独测量每个检索阶段的延迟或准确率。
- 在独立 PostgreSQL 临时 schema 中模拟租约过期：过期任务重新排队，Outbox 生成 `recover=true` 消息，新 worker 获得新租约；旧租约不能把任务标为完成或写入指标；取消后不能再次领取。所有检查通过，临时 schema 已删除。该测试验证数据库状态转换，不等于真实进程崩溃和长时间运行验证。

第一次宿主机测试脚本因环境代理转发 localhost 请求而收到 502；禁用该脚本的代理后，`/ready` 返回 200，正式任务提交与执行成功。这个 502 不是 API 容器的错误。

## 评测参数与取舍

| 参数 | 取值 | 理由 |
|---|---:|---|
| 样例任务并行数 | 1 | 控制服务商限额，便于定位每例错误；因此不能宣称高并发能力 |
| 深度研究最大分支 / worker 数 | 2 / 2 | 覆盖一次并行研究路径，限制调用量和 429 风险 |
| 最大研究轮数 | 1 | 避免烟雾测试反复补查；不能代表复杂调研的充分性 |
| 每分支模型 / 工具调用 | 3 / 3 | 能执行检索和简短综合，同时避免工具循环 |
| 整任务模型调用预算 | 16 | 覆盖守卫、规划、研究、评审、写作及一次修复，超限应显式停止 |
| 单次模型超时 / 协作式任务预算 | 45 / 180 秒 | 约束等待；任务预算不能强制中断已发出的外部请求 |
| 瞬时错误尝试 / 引用修复 | 2 / 1 次 | 给暂时故障或格式问题一次机会，同时限定成本 |
| 写作上下文 | 最多 10000 字符 | 控制小型测试的提示长度；可能遗漏排在后面的证据 |
| 状态轮询 / 截止 | 3 / 210 秒 | 减少轮询自身造成的限流；截止后请求取消 |

这些小样例用于可复现的功能验收：限制模型调用、分支和重试，观察状态、耗时、关键事实、来源类型与引用 ID；容器中的 PostgreSQL、Redis、Celery 和检索链路另行验证。结果不能解释为准确率提升、P95 延迟或高并发成绩。

## 仍需区分的能力边界

- 自动引用校验确认 ID 来自模型实际看过的证据，并检查引用出现在摘要/正文；它不能证明证据语义上支持结论。重要科研结论仍需人工复核或独立的语义评估集。
- 租约保护任务状态、事件、指标写入；失去租约的旧 worker 仍可能已发出外部模型调用，不能宣称端到端 exactly-once。
- 任务取消在节点边界生效，不能立即终止已发出的供应商请求。
- 本次没有执行多用户负载、P95/P99、长期稳定性或实际论文质量测试。4 项跳过的测试及真正的 worker 进程崩溃场景尚未验证。
