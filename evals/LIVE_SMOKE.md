# 小型真实 API 评测说明

本评测使用配置好的聊天模型、Tavily 和可选 Embedding API，研究资料由两个明确标为“合成示例”的文档组成。合成数字只用于验证系统能否提取、比较和正确限定结论，不能视为真实算法实验结果。

## 样例设计

| 用例 | 路径 | 目的 |
|---|---|---|
| `local_facts` | 文档 + 快速问答 | 检查本地上传、检索、数字提取与引用 |
| `local_comparison` | 文档 + 深度调研 | 检查规划、两个来源比较与局限表达 |
| `web_definition` | 网页 + 快速问答 | 检查 Tavily 搜索、网页证据与引用 |
| `hybrid_limits` | 文档和网页 + 深度调研 | 检查混合来源和谨慎结论 |

预期词检查只用于快速发现明显漏答。真正的引用准确性与“引用是否支持结论”仍需人工核对；报告状态 completed 也不等于科研质量合格。

## 参数与选择理由

| 参数 | 本次值 | 原因与限制 |
|---|---:|---|
| 任务并行数 | 1 | 避免四个样例互相争夺供应商限额，便于定位每例耗时；不测系统吞吐 |
| `MAX_WORKERS` | 2 | 深度任务最多允许两个并行研究分支，覆盖并发路径，同时降低 429 风险 |
| `MAX_RESEARCH_SUBTASKS` | 2 | 足够检查问题拆解和并行执行，减少研究分支数量与费用 |
| `MAX_RESEARCH_ITERATIONS` | 1 | 防止一次烟雾测试陷入多轮补查；不能衡量复杂研究的充分性 |
| 单研究分支模型调用上限 | 3 | 限制工具循环，仍允许搜索后进行简短分析 |
| 单研究分支工具调用上限 | 3 | 足够覆盖文档与网页来源，避免重复搜索放大 |
| 整任务模型调用上限 | 16 | 覆盖守卫、规划、研究、评审、写作和一次引用修复；超限应显式失败 |
| 单次模型超时 | 45 秒 | 尽早暴露供应商慢响应，不用无限等待掩盖故障 |
| 任务协作式时间预算 | 180 秒 | 给深度路径留出有限总时间；不是强制终止已发出的线程请求 |
| 瞬时错误尝试次数 | 2 | 允许一次额外尝试，限制费用与等待放大 |
| 引用修复次数 | 1 | 给模型一次纠正机会；再次失败就明确报错，不附加虚假证据索引 |
| 写作上下文上限 | 10000 字符 | 限制网页证据过长造成的响应时间与输出格式波动；可能遗漏较后面的证据，因此只用于小型烟雾测试 |
| 状态轮询间隔 | 3 秒 | 四个连续用例共用一个用户限流窗口，减少自身轮询造成的 429；遇到 429 尊重 Retry-After |
| 每例轮询截止 | 210 秒 | 略高于研究预算，允许任务最终状态写入；到时请求取消 |

本次运行把 `RUNTIME_PROFILE`、任务后端与知识库存储切到本地隔离模式：SQLite + BM25，不写入已在运行的 PostgreSQL 和 Redis。真实模型、Tavily、上传、工作流与引用守卫仍被调用。向量接口单独用两段短文本探测。**这不是生产容器、pgvector、Celery 或高并发验收**，后者仍需 Docker 引擎可用后单独测试。

## 运行方式

在项目根目录，使用当前环境中的 Python：

```powershell
python -m evals.live_smoke `
  --env-file '.env' `
  --output 'outputs/academic-live-smoke.json' `
  --embedding-probe
```

可用 `--case local_facts` 只运行一个样例。脚本不打印密钥，也不把密钥写进结果。输出 JSON 包含报告内容和公开网页信息，分享之前应按自己的数据政策检查。测试使用临时数据库；结果 JSON 可用于复现步骤和分析失败。

## 评测设计说明

四个固定样例覆盖本地事实问答、文档对比、网页问答和混合来源分析。单任务顺序运行、最多两个研究分支、一次评审和最多十六次模型调用，有助于区分逻辑错误、外部服务问题与过载影响，并限制测试成本。自动检查任务状态、引用 ID 对应关系与几个关键事实；语义支持仍需人工核对。这个小样例集用于回归和烟雾测试，不代表总体准确率、高并发能力或真实论文调研质量。
